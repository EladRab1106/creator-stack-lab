How to Auto-Caption Shorts for Free (Whisper + FFmpeg, Copy-Paste Script)

Most people watch Shorts with the sound off, so burned-in captions matter. You don't need a subscription to get the popular 'three big words at a time' style: a free speech-to-text model and FFmpeg can do it on your own computer.

What you need

  • Python 3.9 or newer
  • FFmpeg (on Mac: brew install ffmpeg)
  • The faster-whisper library: pip install faster-whisper

The script

Save this as caption.py. It transcribes the video with word timestamps, groups the words three at a time, writes an ASS subtitle file with big outlined text, and burns it into a new video.

# caption.py - burn word-by-word captions into a video, free and offline
# pip install faster-whisper   (and install ffmpeg)
import subprocess, sys
from faster_whisper import WhisperModel

src, out = sys.argv[1], sys.argv[2]
words = [w for seg in WhisperModel("small", device="cpu", compute_type="int8")
         .transcribe(src, word_timestamps=True)[0] for w in seg.words]

def ts(t):  # seconds -> ASS time h:mm:ss.cc
    return f"{int(t//3600)}:{int(t%3600//60):02d}:{t%60:05.2f}"

lines = ["[Script Info]", "PlayResX: 1080", "PlayResY: 1920", "[V4+ Styles]",
         "Format: Name,Fontname,Fontsize,PrimaryColour,OutlineColour,BackColour,Bold,BorderStyle,Outline,Shadow,Alignment,MarginL,MarginR,MarginV",
         "Style: Cap,Arial Black,84,&H00FFFFFF,&H00000000,&H80000000,1,1,6,2,2,60,60,540",
         "[Events]", "Format: Layer,Start,End,Style,Text"]
for i in range(0, len(words), 3):              # 3 words per caption = easy to read on a phone
    chunk = words[i:i + 3]
    end = words[i + 3].start if i + 3 < len(words) else chunk[-1].end
    text = " ".join(w.word.strip() for w in chunk).upper()
    lines.append(f"Dialogue: 0,{ts(chunk[0].start)},{ts(end)},Cap,{text}")
open("captions.ass", "w").write("\n".join(lines) + "\n")

subprocess.run(["ffmpeg", "-y", "-i", src, "-vf", "ass=captions.ass", "-c:a", "copy", out], check=True)

Run it with python caption.py input.mp4 output.mp4. The first run downloads the model (a few hundred MB). On my laptop a 40-second clip takes well under a minute.

Tweaks that matter

  • Position: the last number in the Style line (540) is the distance from the bottom edge. Keep captions above the bottom ~340 px so the app buttons don't cover them.
  • Size: change 84 to make the text bigger or smaller.
  • Words per caption: change the 3 in the loop. Two to three words reads best on a phone.
  • Accuracy: use the medium model instead of small if names come out wrong. It is slower.
